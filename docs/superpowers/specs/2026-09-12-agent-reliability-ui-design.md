# Agent Reliability UI 优化设计

## 目标
参考 Profy 的暖白工作台风格，提升 Agent Reliability Platform 的信息层级、品牌辨识度和数据阅读体验，同时保持现有路由、API 与交互逻辑不变。

## 视觉系统
- 页面背景采用暖白 `#faf9f6`，内容卡片使用白色，边框使用低对比暖灰。
- 主色为炭黑；状态色采用陶土橙、鼠尾草绿、柔和蓝和琥珀色。
- 统一圆角、阴影、控件高度和间距 token，补充状态、hover、focus、动画变量。
- Geist 作为默认无衬线字体，Geist Mono 用于运行标识、ID 和代码片段。
- 支持浅色为默认，并保留 dark token 兼容性。

## 布局与页面
- 根布局改为左侧固定工作台导航 + 顶部内容区；移动端折叠为顶部导航。
- 侧栏展示产品名、任务与评测入口、当前选中态和底部环境信息。
- 任务页增加清晰的页面标题、摘要统计区、筛选/操作栏和列表容器层级。
- 评测页使用同一页面标题和卡片体系，突出对比结果、成功率和失败类型。
- 统一空状态、加载态、错误卡片和状态徽章的视觉表达。

## 组件边界
优先复用现有 shadcn 原语和已有组件；仅在布局层补充导航、页面壳和统计卡片所需组件。业务数据获取、状态管理与链接路径保持原样。

## 动效与可访问性
- 使用短时、低幅度的 hover/focus/进入动效；尊重 `prefers-reduced-motion`。
- 保证键盘 focus 可见、文本对比度达标、移动端内容不溢出。

## 验证
运行 Web 端 lint/typecheck/build（以仓库现有 scripts 为准），并在浏览器检查桌面与窄屏布局、导航选中态、状态徽章和空/错误状态。
